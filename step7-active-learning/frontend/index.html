Warteschlange wird geladen …

    Ampel-Sprache übernommen aus Konzept-README.md ("Robuste Übereinstimmung" / "Trügerische Ruhe" / "Klarer Fall für Experten-Review"). PGP- und LLM-Einschätzung werden hier bewusst getrennt gezeigt und nie zu einer Zahl verschmolzen – das ist der ganze Sinn der unabhängigen zweiten Meinung.

    In den Details jeder Auftragskarte werden zusätzlich die genutzten RAG-Dokumente mit Vertrauensstufe gezeigt (fehlt sie, wird das als „Vertrauensstufe unbekannt" markiert, nie stillschweigend weggelassen). „Entscheidung erfassen" wird erst nutzbar, nachdem Sie die Details geöffnet haben. Vor dem endgültigen Speichern zeigt ein separater Zwischenschritt, wie viele/welche ähnlichen Aufträge automatisch dieselbe Entscheidung übernehmen würden – erst ein zweiter, eigens beschrifteter Klick speichert die Entscheidung tatsächlich.
